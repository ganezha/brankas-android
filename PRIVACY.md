# Privacy Policy

Brankas does not collect or send user data to the developer or any server. It has no account system, advertising, analytics, tracking SDKs, or internet permission.

Photos, videos, and notes that you choose to add are encrypted and stored in the app's private storage on your device. This local storage is the vault feature; the app does not upload vault contents or recovery codes.

Backups are encrypted. When exporting or restoring a backup, you choose a destination or source through Android's file picker. Brankas itself does not send the backup anywhere. If you choose a cloud-connected file provider, that provider may process or store the file under its own privacy policy.

## Kebijakan Privasi

Brankas tidak mengumpulkan atau mengirim data pengguna kepada pengembang maupun server mana pun. Aplikasi tidak memiliki sistem akun, iklan, analitik, SDK pelacakan, atau izin internet.

Foto, video, dan catatan yang Anda pilih untuk ditambahkan dienkripsi dan disimpan di penyimpanan privat aplikasi pada perangkat. Penyimpanan lokal ini merupakan fungsi brankas; aplikasi tidak mengunggah isi brankas atau kode pemulihan.

Cadangan dienkripsi. Saat mengekspor atau memulihkan cadangan, Anda memilih tujuan atau sumber melalui pemilih file Android. Brankas tidak mengirim cadangan ke mana pun. Jika Anda memilih penyedia file yang terhubung ke cloud, penyedia tersebut dapat memproses atau menyimpan file sesuai kebijakan privasinya sendiri.
